# 📊 Dashboard Comercial com Python e Streamlit

Um dashboard interativo desenvolvido para análise de vendas, utilizando Python, Streamlit, Pandas e Plotly.

## 🚀 Objetivo

O projeto foi criado para demonstrar habilidades em análise de dados, visualização de informações e desenvolvimento de dashboards interativos voltados para tomada de decisão.

## ✨ Funcionalidades

- Filtro de vendas por região
- Indicadores de desempenho (KPIs)
- Faturamento total
- Média de vendas
- Maior venda registrada
- Gráfico interativo de vendas por produto
- Distribuição de vendas por região
- Tabela dinâmica para consulta dos dados

## 🛠️ Tecnologias Utilizadas

- Python
- Streamlit
- Pandas
- Plotly Express
- Git e GitHub

## 📈 Indicadores Monitorados

| Indicador | Descrição |
|-----------|-----------|
| Faturamento | Soma total das vendas |
| Média de Vendas | Valor médio das vendas |
| Maior Venda | Maior valor registrado |

## ▶️ Como Executar

Clone o repositório:

```bash
git clone https://github.com/Maristelacosta/Analise-Vendas-Python-Dashboard.git
```

Acesse a pasta:

```bash
cd Analise-Vendas-Python-Dashboard
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o projeto:

```bash
streamlit run app.py
```
